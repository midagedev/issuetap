# Code of Conduct

Issuetap is a technical project for building and testing Atlassian
clients. The community should stay focused on practical, reproducible
work and clear boundaries around live-site safety.

## Expected Behavior

- Be respectful and direct.
- Discuss ideas, implementation tradeoffs, and evidence.
- Keep issues and pull requests actionable and scoped.
- Never share live Atlassian tokens, site hosts, or real issue data.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without permission.
- Pressuring maintainers to accept live-site credentials in fixtures.
- Using the project as a production Jira.

If a report includes a vulnerability or a possible secret leak, use
`SECURITY.md` instead of a public issue.

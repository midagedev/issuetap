# Support

Issuetap is source-only and pre-release. Support is best effort.

## Choose The Right Channel

Use GitHub issues for:

- reproducible bugs in the Cloud v3 / DC v2 surface, fixtures, scenarios,
  dashboard, or diagnose bundle
- documentation bugs
- coverage gaps in the documented subset

Use the security process in `SECURITY.md` for secret exposure.

## What Issuetap Can Help With

- deterministic local and CI Atlassian scenarios
- proving a client keys on ids, not localized names
- 401 / 429 / truncated-body fault injection
- pointing gadak at a fixture and asserting the mirror

## Out Of Scope

Issuetap is not support for a live Jira or Confluence site. Do not ask
the project to:

- plan work
- debug a production site
- accept live tokens in a public issue
